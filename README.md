# Coding Test Solution: Tasks 1, 2, and 3

This repository contains solutions to the coding test, including a backup script, an automated deployment system, 
and process documentation. Below is an overview of each task, its implementation, and how to use the provided resources.

---

## Task 1: Backup Script

### **File**: `backup_script_task1.sh`

This script automates the process of backing up files from a local mail directory to a remote server 
within a specific date range.

Features:
Selects files based on modification time within a specific date range.
Uses SSH and rsync for secure and efficient file transfer.
Automatically creates directory structures on the remote server.
